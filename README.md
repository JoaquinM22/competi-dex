# Competidex

Sitio web: https://competidex.pages.dev/

Competidex es una aplicación web creada para consultar información de Pokémon de forma rápida, ordenada y visualmente clara.

La plataforma está pensada tanto para fanáticos del competitivo como para jugadores casuales de la saga. Su objetivo es centralizar datos útiles en un solo lugar, combinando información pública con contenido trabajado a mano para ofrecer una experiencia más completa.

## Sobre el proyecto

Competidex se alimenta principalmente de datos públicos, con una fuerte integración con [PokéAPI](https://pokeapi.co/), y además incluye información complementaria desarrollada para la propia web, como formas, relaciones entre componentes y distintas vistas de consulta.

La idea del proyecto es crecer con el tiempo. Esta primera versión ya deja una base sólida, pero en el futuro se le irán sumando más funcionalidades, mejoras visuales y nuevas herramientas.

## Componentes principales

La web está organizada en 6 componentes principales:

1. **Objetos**
   - Consulta y búsqueda de ítems del universo Pokémon.
   - Cada objeto tiene su propia ficha y datos dedicados.

2. **Habilidades**
   - Permite explorar habilidades y sus detalles asociados.
   - Se relaciona con Pokémon y otras vistas del sitio.

3. **Movimientos**
   - Reúne información sobre ataques, aprendizaje y detalles relacionados.
   - Está conectado con Pokémon y con sus formas de obtención.

4. **Pokémon**
   - Es el núcleo principal de la aplicación.
   - Muestra estadísticas, tipos, habilidades, evoluciones, formas, movimientos y más.
   - Se relaciona con gran parte del resto de la aplicación.

5. **Pokédex**
   - Presenta listados organizados por Pokédex y región.
   - Facilita la navegación por generaciones y variantes.

6. **Calculadora de Debilidades y Resistencias**
   - Herramienta de apoyo para analizar combinaciones de tipos.
   - Útil para consultas rápidas y para estrategias competitivas.
   - Considera habilidades especiales que pueden modificar la matriz de daño.

## Características

- Buscadores dedicados por sección.
- Fichas de información específicas para cada entidad.
- Navegación entre componentes relacionados.
- Diseño responsive para escritorio y celulares.
- Modalidades de consulta pensadas para uso rápido y práctico.
